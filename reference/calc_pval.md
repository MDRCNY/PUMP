# Calculates p-values from t-values

Calculates p-values from t-values

## Usage

``` r
calc_pval(rawt, t.df, two.tailed)
```

## Arguments

- rawt:

  vector of t statistics

- t.df:

  degrees of freedom

- two.tailed:

  whether to calculate 1 or 2-tailed p-values

## Value

power results for individual, minimum, complete power
