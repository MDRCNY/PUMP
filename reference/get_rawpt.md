# Function: get_rawpt

Fits models to each of a series of datasets, and extracts p values and t
statistics

## Usage

``` r
get_rawpt(dat.all, d_m, model.params.list)
```

## Arguments

- dat.all:

  list of datasets (of length M)

- d_m:

  design/model

- model.params.list:

  list of model parameters
